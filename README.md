## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Python,Google Colab,Sklearn

Step 1:Clone repository

```bash
git clone https://github.com/alvinadar/Decision-Tree-Algorithm-Basic.git)](https://github.com/alvinadar/Decision-Tree-Algorithm-Basic.git
```

Step 2 : Navigate to the project directory
```bash
cd Decision-Tree-Algorithm-Basic
```

Step 3 : Install dependencies
```bash
npm install
```

Step 4 : Set up environment variables (if applicable)
```bash
cp .env.example .env
```
